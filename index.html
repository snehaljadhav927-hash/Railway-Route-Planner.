How A* Works

A* evaluates each station using the function:

f(n) = g(n) + h(n)

  • g(n): Distance traveled from the source.
  • h(n): Estimated remaining distance to the destination.
  • f(n): Estimated total route distance through a station.

This demonstration uses straight-line estimates as the heuristic and track distances as edge costs. Its railway data is illustrative.
